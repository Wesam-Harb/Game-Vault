# 🎮 Game Explorer

A modern, responsive web application for discovering video games across different platforms and generations. Built as part of my professional front-end development training.

## 🚀 Live Demo

https://game-vault-beige-ten.vercel.app/

## ✨ Key Features

- **Dynamic Routing:** Specialized views for PlayStation, Xbox, and PC using React Router.
- **Smart Search:** Debounced search functionality that stays synchronized with the URL for easy sharing.
- **Advanced Filtering:** Filter games by generation (PS5, PS4, etc.), genre, and mood.
- **Responsive UI:** Fully optimized for mobile and desktop using Tailwind CSS and Material UI.
- **Skeleton Loading:** Custom loading states to ensure a smooth user experience during API fetches.

## 🛠️ Tech Stack

- **Framework:** React (Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Material UI (MUI)
- **Routing:** React Router 7
- **API:** RAWG Video Games Database API
- **Deployment:** Vercel

## 📦 Installation & Setup

1. Clone the repo: `git clone https://github.com/Wesam-Harb/Game-Vault.git`
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`

## 💡 What I Learned

During this project, I mastered handling complex `useEffect` synchronization, managing URL search parameters for state persistence, and optimizing React component re-renders using `useMemo` and `key` props.
